Introduction

API documentation for the MailMaster newsletter management system

Base URL: http://localhost 
This documentation aims to provide all the information you need to work with our API.

<aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>

Authenticating requests

This API is not authenticated.

Campaign Management

API endpoints for managing campaign sending and statistics

Send a campaign

Sends the campaign to all active subscribers in the associated newsletter.

Example request:
curl --request POST \
    "http://localhost/api/campaigns/1/send" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost/api/campaigns/1/send"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

fetch(url, {
    method: "POST",
    headers,
}).then(response => response.json());

Example response (200):


{
    "success": true,
    "message": "Campaign sent successfully: 10 sent, 0 failed",
    "sent_count": 10,
    "failed_count": 0
}

Example response (400):


{
    "success": false,
    "message": "This campaign has already been sent"
}
Received response:
Request failed with error:


Tip: Check that you're properly connected to the network.
If you're a maintainer of ths API, verify that your API is running and you've enabled CORS.
You can check the Dev Tools console for debugging information.

Schedule a campaign

Schedule a campaign for future sending.

Example request:
curl --request POST \
    "http://localhost/api/campaigns/1/schedule" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"scheduled_at\": \"2023-05-15 10:00:00\"
}"

const url = new URL(
    "http://localhost/api/campaigns/1/schedule"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "scheduled_at": "2023-05-15 10:00:00"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (200):


{
    "message": "Campaign scheduled successfully",
